# 편의점 입지 추천 서비스 — 서초 추가 수집 데이터

팀 공유 원천 묶음에는 소상공인 상가정보와 공동주택이 강남·송파만 들어 있습니다. 페르소나 B 후보를 도곡동 반경 1.5km 생활권(서초구 포함, 기준서 13-2)으로 정하면서 서초구 분을 같은 API로 추가 수집했습니다. 팀 공유 원천 묶음과 **함께** 쓰는 파일이며, 강남·송파 파일을 대신하지 않습니다.

## 1. 들어 있는 것

| 이름 | 출처 | 행수 | 수집 일시 |
|---|---|---|---|
| 소상공인_상가정보_서초 | 공공데이터포털 소상공인시장진흥공단 상가(상권)정보 API storeListInDong | 40,115 | 2026-10-07T22:32:29+09:00 |
| 공동주택_서초 | 공공데이터포털 국토교통부 공동주택 API + 브이월드 지오코딩 | 203 | 2026-10-07T22:39:17+09:00 |

## 2. 파일

- `data/` — 엑셀에서 바로 열리는 CSV (UTF-8 BOM). 팀 공유 원천 묶음과 같은 폴더 구조입니다
- `parquet/` — 원본 parquet. 저장소의 `data/raw_v2/` 아래 같은 경로에 그대로 넣으면 분석 코드가 서초 파일을 자동으로 붙입니다

- `data/data_go_kr/14_소상공인_상가정보/상가정보_서초.csv`
- `data/data_go_kr/12_13_18_공동주택/공동주택_서초_단지목록.csv`
- `data/data_go_kr/12_13_18_공동주택/공동주택_서초_기본정보.csv`
- `data/data_go_kr/12_13_18_공동주택/공동주택_서초_좌표변환.csv`

## 3. 쓰는 법

강남·송파 파일과 행을 이어 붙여(concat) 쓰면 됩니다. 코드값은 문자열로 읽으세요.

```python
import pandas as pd
shops = pd.concat([pd.read_csv(p, dtype=str, encoding="utf-8-sig") for p in
                   ["data/data_go_kr/14_소상공인_상가정보/상가정보_강남송파.csv",
                    "data/data_go_kr/14_소상공인_상가정보/상가정보_서초.csv"]], ignore_index=True)
```

## 4. 주의

- 상가정보에는 같은 점포가 두 번 등록된 경우가 있습니다. 편의점 수를 셀 때 상호명 + 도로명주소로 중복을 빼세요 (기준서 13-1)
- 공동주택은 관리정보시스템 가입 단지만 포함됩니다
- 출처: 공공데이터포털 소상공인시장진흥공단 상가(상권)정보 API, 국토교통부 공동주택 API, 브이월드 지오코딩 (이용 조건은 팀 공유 원천 묶음 README 5절과 같습니다)
- 인증키는 들어 있지 않습니다
