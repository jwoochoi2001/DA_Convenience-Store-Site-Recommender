# 편의점 입지 추천 서비스 — 원천 데이터 묶음

강남구·송파구 편의점 입지 분석을 위해 팀이 수집한 원천 데이터입니다. 이 묶음 하나로 EDA를 진행합니다.
수집 과정의 검증을 모두 통과한 데이터만 담았으며, 원본 값은 가공하지 않았습니다.

**지역 범위 주의:** 서울 열린데이터광장 데이터(1–10번)는 강남·송파만이 아니라 **서울 전체**(상권 1,650개, 행정동 전체)가 들어 있습니다. 서울 평균과 비교하는 지표를 만들 수 있도록 일부러 전체를 받았습니다. 강남·송파만 볼 때는 상권 코드나 행정동 코드로 걸러 쓰세요. 소상공인 상가정보(14번)와 공동주택(12·13번)은 강남·송파만 들어 있습니다.

## 1. 파일 형식

- 데이터는 모두 **CSV (UTF-8 BOM)** 입니다. 엑셀에서 한글이 깨지지 않고 바로 열립니다.
- 엑셀은 한 시트에 약 104만 행까지만 열 수 있어서, 이를 넘는 **점포 데이터는 연도별 파일로 나눴습니다.**
- 상권 경계만 지도 도형이라 CSV로 바꿀 수 없어 zip(shapefile) 그대로 넣었습니다. 좌표계는 EPSG:5181입니다.
- `파일목록.csv` 에 파일마다 행수와 파일 지문(SHA256)이 있습니다. 같은 파일인지 확인할 때 지문을 비교하세요.

## 2. 파이썬으로 읽는 법

코드값의 앞자리 0이 사라지지 않도록 문자열로 읽은 뒤 필요한 열만 숫자로 바꾸세요.

```python
import pandas as pd
df = pd.read_csv("data/seoul/01_추정매출_상권/추정매출_상권.csv", dtype=str, encoding="utf-8-sig")
df["THSMON_SELNG_AMT"] = pd.to_numeric(df["THSMON_SELNG_AMT"])
```

연도별로 나뉜 파일은 합쳐서 읽습니다.

```python
from pathlib import Path
files = sorted(Path("data/seoul/02_점포_상권").glob("점포_상권_*.csv"))
store = pd.concat([pd.read_csv(f, dtype=str, encoding="utf-8-sig") for f in files], ignore_index=True)
```
